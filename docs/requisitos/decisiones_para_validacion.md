# Decisiones para validación del Product Owner (PS-S0-08, PS-S2-15)

Las ambigüedades de los documentos de requisitos se resolvieron con **supuestos del equipo** (D-01..D-29, fuente: `docs/requisitos/matriz_trazabilidad.md`, sección 2). Este documento es la hoja de revisión: el Product Owner (PO) marca cada decisión como **Aprobada**, **Rechazada** o **Ajustar** y firma. La validación no puede darse por hecha desde el código, por eso PS-S0-08 y PS-S2-15 siguen en 🟡 hasta que la columna de firma esté completa.

**Cómo usarla**

1. Revisar cada fila (la decisión implementada está en la columna 3; la justificación, en la 4).
2. Si se rechaza o ajusta, la columna 5 indica qué se cambia y dónde (la mayoría son datos o variables de entorno, sin tocar el esquema).
3. Anotar el resultado, el nombre del PO y la fecha en la columna de firma; las decisiones rechazadas se convierten en tareas.
4. Con todas las filas firmadas, actualizar PS-S0-08 y PS-S2-15 a ✅ en la matriz.
